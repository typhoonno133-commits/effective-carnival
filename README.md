# effective-carnival

リツキの道具箱 — アオイとリツキのスキル置き場です。

## skills/ — Remotion 公式 Agent Skills

`skills/` には、Remotion 公式の Agent Skills 13件のコピーを置いています。

- 出典: [remotion-dev/skills](https://github.com/remotion-dev/skills)
- 導入方法（公式）: `npx skills add remotion-dev/skills` または `npx remotion skills add`
- ライセンス: Remotion のライセンスに従います（`skills/remotion-license/` の注記を参照）

内訳: remotion-best-practices / remotion-create / remotion-markup / remotion-studio / remotion-render / remotion-maps / remotion-captions / remotion-saas / remotion-interactivity / remotion-docs / remotion-license / remotion-upgrade / remotion-multimedia

Remotion はコードでアニメーションを作るためのレシピ集です。AI動画生成とは別物で、3Dモデリングのスキルではありません。
